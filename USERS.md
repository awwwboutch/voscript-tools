## What "a convention changed" means

Not every commit needs a heads-up. These do, because scripts already written against the old
version keep compiling and silently do the wrong thing:

- A named-list rule changes — what a translation holds, or how spoken forms are written.
- An addressing idiom is corrected — how a control is found, or which ControlType it is.
- A rule in `shared/references/conventions.md` changes rather than being added to.

Three of these landed on the first day the plugin existed, so assume it will keep happening.
