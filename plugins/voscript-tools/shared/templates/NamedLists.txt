Generated {{Date}} by the voscript-starter skill.

Format is  Text\Spoken form
  Text          the value the script receives from SpeechParams.TranslateSingle()
  Spoken form   what the pathologist says, written to the Dragon rules below

To accept more than one way of saying the same thing, pipe-separate the spoken forms:
  0.1x\point one X|zero point one X

Each block below is ready to copy and paste into the Global Named List Manager. Delete any list
this system does not support rather than leaving it half-filled, and replace every TODO with a
value read off the live application.

A translation holds ONLY the part of the phrase that varies. The invariant words live in the
command trigger, so "zoom <{{System}}Magnifications>" means the list holds 20x, never Zoom to 20x.
If the on-screen caption needs more than the spoken value, compose it in the script.

--------------------------------------------------------------------------------
DRAGON SPOKEN FORM RULES
--------------------------------------------------------------------------------
  No punctuation           0.1x\point one X       not  0.1X
  Numbers written as words 20x\twenty X           not  20X
  Acronyms spaced out,
  letters capitalised      MRN\M R N              not  MRN
  Multiple spoken forms
  are pipe-separated       0.1x\point one X|zero point one X

Text keeps whatever casing and punctuation the script or the UI needs. Only the spoken form
follows these rules.

Some lists already in GlobalSetup predate this and hold spoken forms like "10X" and "point 1X".
Do not copy them as a pattern - write new lists to the rules above.
